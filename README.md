EduSync is a comprehensive, role-based educational management system designed to bridge the communication gap between educational stakeholders. It streamlines resource management, real-time communication, and interactive performance tracking.

## Features

**Super Admin Module**
* Complete user lifecycle management 
* Role-Based Access Control (RBAC) enforcement
* System-wide global announcement broadcasting
* Review, approve, or reject study materials uploaded by teachers
* Monitor system activity logs

**Principal Module**
* High-level dashboard for administrative oversight
* Monitor school activities and system-wide statistics

**Teacher Module**
* Upload study notes, slides, and assignments categorized by class and subject
* Post targeted announcements to specific classes and sections
* Manage a professional profile accessible via the directory

**Student Module**
* Access and download approved study materials
* Track academic performance through interactive result progress graphs
* Receive and view targeted announcements
* Access the teacher contact directory

## Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript, Chart.js
* **Backend:** PHP (Core)
* **Database:** MySQL
